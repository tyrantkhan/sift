# sift plugin

This branch holds only the sift plugin for Claude Code: its manifest, skill and session hook. A release job publishes it from [main](https://github.com/tyrantkhan/sift) at each release and replaces everything here, so changes MUST go to main.

The plugin needs the `sift` command on your PATH. Install it as [the README on main](https://github.com/tyrantkhan/sift#install-the-cli) describes.
